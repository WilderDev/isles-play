# Emberlight Isles

A cozy creature-befriending, island-exploring, home-building adventure. **Play: https://wilderdev.github.io/isles-play/**

This repo only holds the built game (`index.html`, `game.js`, `assets/`), published from the private source repo.
No internet? Download **emberlight-offline.html** and double-click it (everything in one file).
